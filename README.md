Ejecuta la primera celda e introduce la contraseña facilitada en el curso. El código se prepara automáticamente en tu sesión de Colab. Puedes leer y editar los archivos Python desde **Archivos → curso-motorsport → src → race_models**.

No necesitas descargar ni subir archivos manualmente. Guarda una copia del notebook en Drive. Los cambios en archivos Python de la sesión son temporales.

Este repositorio contiene únicamente los notebooks de entrada. La contraseña y el paquete del simulador no están publicados aquí.
